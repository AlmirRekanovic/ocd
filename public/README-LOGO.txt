OCD FIGHTERS — LOGO
===================

Spasi logo kluba u ovaj folder pod tačnim imenom:

    public/logo.png

Koristi se automatski na: početnoj stranici (veliko u hero sekciji),
u navigaciji, na stranicama za prijavu i u admin panelu, te kao ikona
taba u browseru (favicon).

Preporuka:
- PNG sa providnom (transparent) pozadinom izgleda najbolje.
- Širi/horizontalni logo ("OCD FIGHTERS") — visina se prilagođava sama.
- Ako fajl ne postoji, sajt prikazuje stilizovani tekst "OCD FIGHTERS"
  umjesto slike (ništa se ne lomi).

Nakon što dodaš fajl, sačuvaj na GitHub:
    git add public/logo.png
    git commit -m "Add club logo"
    git push
